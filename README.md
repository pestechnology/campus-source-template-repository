## 🚀 Getting Started

### 1. Prerequisites
- **Node.js**: v18.x or v20.x
- **Git**: Latest version installed

### 2. Upstream Setup & Cloning
First, fork this repository on GitHub. Then clone your fork locally:
```bash
git clone https://github.com/YOUR_USERNAME/campus-source.git
cd campus-source
git remote add upstream https://github.com/pestechnology/campus-source-template-repository.git
```

### 3. Branching & Development
Always create a feature branch before making changes:
```bash
git checkout -b feat/your-feature-name
# Make your changes
git add .
git commit -m "feat: your descriptive commit message"
```

### 4. Syncing & Pull Request
Before pushing, stay synced with the upstream `main`:
```bash
git fetch upstream
git merge upstream/main
git push origin feat/your-feature-name
```
Finally, open a Pull Request through the GitHub UI.

## 🤝 Contribution Flow
1. **Find**: Browse issues with `good-first-issue` label.
2. **Claim**: Comment on the issue to let others know you're working on it.
3. **Fork**: Create your own copy of the repo.
4. **Code**: Implement your changes following the [CONTRIBUTING.md](CONTRIBUTING.md) guide.
5. **PR**: Submit your Pull Request for review.
6. **Merged**: Congratulations, you're now a contributor!

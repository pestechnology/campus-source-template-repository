# ⚙️ How to Finalize this Template on GitHub

To make this repository a functional GitHub Template, follow these final steps in your GitHub UI:

## 1. Enable Template Mode
1. Go to your repository's **Settings** tab.
2. Under the **General** section, find the checkbox labeled **"Template repository"**.
3. **Check this box.** This will enable the "Use this template" button for all students.

## 2. Set Up GitHub Discussions
1. In **Settings > General**, scroll down to the **Features** section.
2. Check the box for **"Discussions"**.
3. This creates a place for your community to have async chats (Layer 1 of our strategy).

## 3. Configure Branch Protection (Recommended)
1. Go to **Settings > Branches**.
2. Click **Add rule** for the `main` branch.
3. Enable **"Require a pull request before merging"**.
4. This ensures all student contributions go through the review process we've set up.

## 4. Add Repository Topics
Add these tags to your repository's ABOUT section to help students find it:
`campus-source`, `student-project`, `hacktoberfest`, `open-source-template`.

---
*Once you've completed these steps, you can safely delete this `TEMPLATE.md` file.*

# 🗺️ Project Roadmap

This roadmap outlines the planned evolution of Campus Source. As a community-driven project, these goals are flexible and driven by student needs!

## 🗓️ Phase 1: Foundation (Current)
*Focus: Stability and Ease of Entry*
- [x] Baseline project structure.
- [x] Standard GitHub issue/PR templates.
- [x] Discord community integration.
- [ ] Comprehensive setup guides for all OS.
- [ ] Automated "Welcome" bot for 1st-time PRs.

## 🗓️ Phase 2: Growth (Next Q)
*Focus: Feature Parity & Engagement*
- [ ] Web-based Leaderboard UI.
- [ ] Automated badge generation for Contributor Profiles.
- [ ] Mentorship pairing system integration.
- [ ] Multi-campus support (Sub-communities).

## 🗓️ Phase 3: Scaling (Future)
*Focus: Long-term Impact*
- [ ] Official "Campus Source" API for student apps.
- [ ] Integration with Campus LMS systems.
- [ ] Annual "Campus Source Summit" (Virtual/Hybrid).

### 💡 Have an Idea?
We value your input! If you have a feature suggestion, please:
1.  Check the [Project Board](https://github.com/campus-source/template/projects) to see if it's already there.
2.  Open a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md).
3.  Discuss it in our `#ideas` channel on [Discord](https://discord.gg/campus-events).

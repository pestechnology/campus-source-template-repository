# Security Policy

## Supported Versions

We only provide security updates for the current version of the project.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

## Reporting a Vulnerability

If you discover a security vulnerability within Campus Source, please do **not** open a public issue. Instead, please follow these steps:

1.  Email a description of the vulnerability to [security@campussource.org](mailto:security@campussource.org).
2.  Include details on how to reproduce the issue.
3.  Allow the maintainers up to 7 days to respond before disclosing the issue publicly.

We appreciate your help in keeping Campus Source safe for all students!

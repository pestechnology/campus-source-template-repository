# 🏷️ Labeling Guide

We use labels to organize work and help you find the right task. Here’s what they mean:

## 🟢 For Beginners
- `good first issue`: Ideal for 1st-time contributors. Small scope, clear instructions.
- `help wanted`: We need someone to take this on. Moderate difficulty.
- `documentation`: Help us improve our guides and READMEs.

## 🔵 Task Types
- `enhancement`: New features or improvements.
- `bug`: Something isn't working as it should.
- `refactor`: Improvements to code structure without changing functionality.
- `tests`: Adding or fixing unit/integration tests.

## 🟠 Status Labels
- `triage`: New issue that hasn't been reviewed yet.
- `in-progress`: Someone is currently working on this.
- `waiting-for-review`: PR is open and needs a maintainer's eyes.
- `stale`: No activity for a while.

## 🟣 External Programs
- `hacktoberfest`: Part of the annual open-source celebration.
- `gssoc`: GirlScript Summer of Code task.

---
*Tip: You can filter issues by labels by clicking them on the Issue list page!*

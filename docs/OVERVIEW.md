# 🌐 Project Overview

Campus Source is a modular, community-first framework designed to help students build, manage, and scale campus-wide projects. 

## 🎯 Our Mission
To bridge the gap between classroom theory and real-world engineering by providing a professional environment where students can contribute to meaningful code.

## 🏗️ Technical Architecture
The project follows a "Clean Architecture" philosophy:
- **`src/`**: Contains the core logic and UI components.
- **`tests/`**: Mirroring the `src` structure for easy unit and integration testing.
- **`docs/`**: A comprehensive knowledge base for users, contributors, and maintainers.
- **`.github/`**: Automation layer (CI/CD, triage, welcoming).

## 📊 Community Layers
We operate on a three-layer communication strategy:
1.  **Fast Layer (Discord)**: Real-time chat, debugging, and social bonding.
2.  **Semi-Fast Layer (GitHub Discussions)**: Q&A, RFCs (Request for Comments), and Show-and-Tell.
3.  **Permanent Layer (Documentation/Git)**: Roadmap, README, and finalized code.

## 🏅 Recognition & Rewards
We celebrate contributions through our gamified levels:
- **Bronze**: Entry-level proficiency.
- **Silver**: Consistent contributor & reviewer.
- **Gold**: Strategic lead & mentor.

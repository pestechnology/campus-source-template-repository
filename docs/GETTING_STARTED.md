# 🎓 Getting Started with Campus Source

Welcome to the family! This guide will walk you through your first 30 minutes with the project.

## 🏁 1. Environment & Setup (10 mins)
1.  **Check Prerequisites**: Ensure you have Node.js and Git installed. See our [Environment Setup Guide](ENVIRONMENT_SETUP.md) for OS-specific help.
2.  **Fork the repo**: Click the "Fork" button on the top right.
3.  **Clone it**: 
    ```bash
    git clone https://github.com/YOUR_USERNAME/campus-source-template.git
    cd campus-source-template
    ```
4.  **Install & Run**:
    ```bash
    npm install
    npm run dev
    ```

## 🛠️ 2. Finding Your First Task (10 mins)
- Go to the **Issues** tab.
- Look for the label `good first issue`. These are small tasks (typo fixes, CSS tweaks) designed to help you learn the workflow.
- Comment on the issue: *"I'd like to work on this!"*. A maintainer will assign it to you.

## 🤝 3. Making Your First PR (10 mins)
1.  **Create a branch**: `git checkout -b fix/my-first-fix`
2.  **Make changes**: Edit the code and save.
3.  **Commit**: `git commit -m "docs: fix typo in README"`
4.  **Push**: `git push origin fix/my-first-fix`
5.  **Open PR**: Go to your fork on GitHub and click "Compare & pull request".

## 🏆 4. Leveling Up (5 mins)
- Once your PR is merged, you are officially a **Bronze Contributor**!
- Join our **[Discord](https://discord.gg/campus-events)** and head to `#introductions` to get your server role.

---

## 💡 Pro Tips
- **Ask for help**: Don't spend more than 30 minutes stuck. Ask in Discord or comment on the issue.
- **Review others**: You can learn a lot by looking at other people's PRs!

*Happy hacking!*

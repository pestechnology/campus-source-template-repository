# 🧑‍🔬 Maintainer Guide

Maintainers are the heart of the Campus Source community. They don't just write code; they mentor, review, and grow the community.

## 🚀 The Path to Maintainership

We believe in a transparent path to leadership:

1.  **Contributor**: Submit your first PR (Bronze).
2.  **Regular**: Reach Silver status (5 PRs) and start helping others in Discord.
3.  **Triage**: Reach Gold status (10 PRs). You will be invited to help label issues and review small PRs.
4.  **Maintainer**: After consistent Gold-level contribution and peer nomination, you'll be granted "Write" access to the repository.

## 📋 Maintainer Responsibilities

- **Review PRs**: Provide constructive, kind feedback. Focus on "Learning" as much as "Code".
- **Label Issues**: Ensure new issues are triaged within 48 hours.
- **Moderate Discord**: Keep our virtual campus a safe and welcoming space for all.
- **Update Roadmap**: Help define the next steps for the project.

## ⚖️ Code Review Values

When reviewing a student's PR, follow these principles:
- **Be Kind**: Remember that for many, this is their first open-source experience.
- **Explain "Why"**: Don't just point out a bug; explain why it's a bug and how to fix it.
- **Celebrate Success**: Use emojis (🎉, 🚀, 👍) to celebrate merged contributions!

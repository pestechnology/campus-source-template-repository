Contribution Flow

01

Find & Claim

Find an issue with the good-first-issue label and claim it in the comments.

02

Fork & Setup

Fork the repository and set up your local development environment using the setup guide.

03

Code & Test

Implement your feature or fix. Follow our commit conventions and ensure tests pass locally.

04

Submit PR

Push your changes and open a Pull Request. Fill out the PR template with all required details.

05

Peer Review

Maintainers will review your code. Engage with feedback and iterate on your branch.

06

Merged!

Your contribution is officially part of the project. Welcome to the Campus Source hall of fame!

Quick Start

# Clone your fork
git clone https://github.com/USER/campus-source.git
cd campus-source

# Install and branch
npm install
git checkout -b feat/cool-feature

# Commit following conventions
git commit -m "feat(ui): add modern card animations"

# 🏗️ Discord Server Structure

Our Discord server is our virtual office. Here is how it is structured to help you navigate:

## 📢 Public Channels
- `#announcements`: Critical updates about milestones and meetings.
- `#general`: High-level chat and community interaction.

## 🛠️ Contributor Workspace
- `#beginner-issues`: A dedicated space for those making their first PR.
- `#help-support`: Technical help with setup or bugs.
- `#project-discussion`: Debating features and code architecture.

## 🏅 Operations
- `#contributors`: A channel for active contributors to sync (Role restricted).
- `#maintainers`: Private channel for project governance.

## 🎙️ Voice Channels
- `#community-call`: Where we host our weekly Saturday syncs.
- `#co-working`: Jump in here anytime to code together in silence.
